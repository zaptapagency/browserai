QUICK START
===========
Local:
  pnpm install
  docker-compose up -d
  pnpm --filter @browserai/db run migrate
  pnpm dev

Railway:
  1. Push to GitHub: git push origin main
  2. Go to https://railway.app/dashboard
  3. Click "New Project" → "Deploy from GitHub"
  4. Select browserai repo
  5. Set environment variables
  6. Deploy ✅
